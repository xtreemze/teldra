# Public Studio demo

`demo.teldra` is a small Teldra-authored synthetic room derived from the repository's Golden Home fixture.
It contains a schematic chair, floor lamp, floor and walls, canonical IFC identities, and a sample device with no external-system binding.
It contains no 21D or other private home data and makes no physical device requests.

Regenerate with the Python workspace dependencies and `python tools/fixtures/generate_studio_demo.py`.
Source geometry and palette are authored in that script. Do not substitute the real 21D project in the public build.
